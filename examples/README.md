# SWITH examples

Each folder is a self-contained, small project. Open the folder, then double-click the `.search` file after installing SEARCH Studio.

| Example | Demonstrates |
| --- | --- |
| [Task board](task-board/) | UI state, list updates and actions |
| [Contact book](contact-book/) | form input and simple records |
| [API counter](api-counter/) | page action plus an API endpoint |
